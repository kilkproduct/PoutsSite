Set up the basics.
Keep things simple.

Use this guide to get Pouts ready for your server, understand permissions, and troubleshoot the most common command issues.

Add Pouts to a server

Ask a server owner or administrator to add Pouts using its official Discord invite. Review the requested permissions before confirming; only grant the access needed for the features you plan to use.

Run a slash command

In a channel where apps are allowed, type / and choose a Pouts command from Discord’s menu. Fill in the requested options, then submit it. The reply may be visible only to you or posted in the channel.

Browse the command list →

Set moderation permissions

Moderation actions depend on both the bot’s permissions and Discord’s role hierarchy. Deleting messages requires Manage Messages; timeouts require Moderate Members. Keep the Pouts role above the roles it needs to moderate.

If a command is missing

  • Confirm Pouts is still in the server and can access the channel.
  • Check that your role is allowed to use the command and its options.
  • For moderation, ask an administrator to review the bot’s permissions and role order.
  • Close and reopen Discord’s command picker after a permission change.
